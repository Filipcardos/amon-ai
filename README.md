O **Amon IA** é um assistente virtual com inteligência artificial desenvolvido em Python, focado em educação financeira e experiência do usuário.

A aplicação permite interação em linguagem natural para responder dúvidas financeiras, sugerir boas práticas e auxiliar na tomada de decisões.

---

# 🌐 Acesse o projeto online

 https://amon-ai.streamlit.app/

---

# Tecnologias Utilizadas

- Python
- Streamlit
- OpenRouter (API de IA)
- OpenAI SDK
- dotenv

---

#  Funcionalidades

- 💬 Chat interativo com IA
- 🧠 Respostas contextualizadas com histórico de conversa
- 💳 Assistente especializado em finanças pessoais
- ⚡ Interface moderna estilo ChatGPT
- 🔐 Uso seguro de variáveis de ambiente (.env / secrets)
- 🌐 Deploy online (Streamlit Cloud)

---

# 🧠 Diferenciais do Projeto

- ✅ Arquitetura modular (services/)
- ✅ Engenharia de prompt para evitar respostas incorretas
- ✅ Tratamento de erros
- ✅ Experiência do usuário (UX) aprimorada
- ✅ Interface visual moderna e responsiva
- ✅ Deploy automatizado via GitHub
